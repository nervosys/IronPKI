# Requirements traceability

This matrix links every requirement tagged in the source to the code that
implements it and the test that shows it holds. It is **checked by a test**:
`tests/traceability.rs` fails if a `REQ-*` tag in `src/` is missing here, if a
row names a requirement the source does not carry, or if a cited test
function does not exist.

Verification is by **Test** throughout: each row names the test functions
that fail when the requirement is broken.

## Where the requirements came from

Most were written for IronSocketLayer, whose certificate code this crate was
extracted from at its 0.3.4, and keep the identifiers they had there, so that
a requirement can be followed from one repository to the other:
`REQ-X509-001` to `079`, `REQ-CRL-*`, `REQ-OCSP-*`, and three others whose
code moved with them (`REQ-FIX-003`, the fixed-slot validator; `REQ-CFG-008`
and `REQ-RPT-003`, reworded below for what holds in this crate).
`REQ-X509-080` onwards were written here.

Requirements about how a TLS handshake uses a certificate (pinning a server's
key, a stapled response and the revocation policy, reporting a peer's names)
stayed in IronSocketLayer and are not in this matrix.

Rows whose evidence in IronSocketLayer included handshake tests cite only the
tests that are in this repository.
