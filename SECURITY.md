# Security

IronPKI is a scaffold. It has had no security review and makes no security
claims yet. Do not depend on it in production.

Please report a suspected vulnerability privately through GitHub's security
advisories for the repository once it is published, not in a public issue.
Until then, report it to the maintainer directly.

Nothing in IronPKI is FIPS 140-3 validated. IronCrypto, which it builds on, is
not CMVP validated; a validation is planned, with no date.
